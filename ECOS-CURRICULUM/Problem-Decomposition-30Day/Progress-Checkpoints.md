# Progress Checkpoints

Run these at the end of each week (Days 7, 14, 21, 30). They tell you whether to continue,
go back, or speed up. Be honest — the only person you fool by inflating a self-score is you.

---

## End of Week 1 (Day 7) — Foundations

**On track if you can:**
- Explain MECE to someone else in two sentences, with an example.
- Build a 2-level issue tree for a fresh problem and pass the §8 master checklist.
- Spot an overlap and a gap in a flawed structure.

**Remediate (redo these days) if:**
- Your trees still come out as flat brainstorm lists → redo **Day 4**.
- You can't tell whether a structure is MECE → redo **Days 2 & 5**.
- You build tidy trees that don't help answer anything → redo **Day 6**.

**Accelerate if:** all of the above are easy → skim Day 8, go straight to the harder Week-2
cases, and add a stretch exercise each day.

---

## End of Week 2 (Day 14) — Practice across types

**On track if you can:**
- Pick a sensible cut type for a profit, a segmentation, and a process problem.
- Run a 5-Whys to a *root* cause (not a symptom).
- Decompose an everyday decision into weighted factors.

**Remediate if:**
- You default to the same cut for every problem → redo **Day 3**, preview **Day 21**.
- Your root-cause hunts stop at symptoms → redo **Day 11**.
- Profit/driver trees feel shaky → redo **Day 8** (it's the workhorse).

**Accelerate if:** comfortable → spend extra time on Week 3, which is the real skill.

---

## End of Week 3 (Day 21) — Choosing the lens (the crux)

**On track if you can:**
- Look at a fuzzy problem and name a lens *with a reason*, using the cheat sheet.
- Explain when MECE is the *wrong* tool and what to use instead.
- Re-structure one problem through ≥3 lenses and say what each reveals and hides.
- Handle a two-lens-plausible case by sequencing lenses and naming a switch condition.

**Remediate if:**
- You still reach for MECE reflexively → redo **Days 16 & 17**.
- Lenses blur together → redo the recurring-case days (**15–20**) one at a time.
- You pick a lens but can't justify it → redo **Day 21** with the diagnostic questions.

**Accelerate if:** lens-selection feels natural → go light on Week 4's mechanics and invest
in the capstone.

> This is the most important checkpoint. If only one week sticks, make it this one.

---

## End of Week 4 / Program (Day 30) — Synthesis & delivery

**On track if you can:**
- Turn a structure into an analysis plan with evidence and sources.
- Synthesize findings into one governing message (pyramid).
- Write an answer-first, one-page executive summary with action titles.
- Complete the capstone end-to-end: choose a structure, analyze, recommend.

**Remediate if:**
- Your summaries bury the answer → redo **Day 24**.
- Findings don't add up to a message → redo **Day 23**.
- The capstone structure was shaky → revisit **Day 21** before re-attempting.
