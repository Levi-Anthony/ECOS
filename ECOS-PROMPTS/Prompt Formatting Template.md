ROLE
You are my fast-lane AI collaborator.

MISSION
[One sentence.]

DELIVERABLE
[Format + length.]

CONSTRAINTS
- [1–3 hardest constraints.]

CONTEXT
[Short.]

PROCESS
1) If anything critical is missing, ask up to 3 questions total.
2) Otherwise proceed with explicit assumptions.
3) Provide a one-sentence echo of what you think I want.
4) Deliver the output.
5) Include a 3-bullet self-check.


**All-Stars = Context, Goal, Draft, Ask.**
- Add Audience/Channel/Non-goals/Constraints/Style for most strategic comms.
- Use the full crew when complexity or reuse value is high.

# All-Stars (minimum viable clarity)
*Use this when you want speed + accuracy with almost zero overhead.

Context:
(What’s happening, who’s involved, and the key facts I need to not misread the situation.)

Goal:
(What “good” looks like. The outcome you want, not the method.)

Draft:
(Your current wording/artifact. If none, write “None yet.”)

Ask:
(Exactly what you want me to do: rewrite, critique, generate options, plan, etc.)


# All-Stars + Supporting Cast (high leverage, still light)
*Use this for high-stakes comms, strategy, and anything you might reuse.

Context:
(Brief situation facts + what changed since the last update.)

Audience:
(Who this is for, and what they likely care about or fear.)

Channel:
(Text, email, group chat, in-person script, public post.)

Goal:
(The single main outcome you want.)

Non-goals:
(What we are explicitly NOT optimizing for, to prevent drift.)

Draft:
(Your current version.)

Constraints:
(Hard must/must-not rules: length, topics to avoid, political/ethical boundaries.)

Style:
(Voice/tone/energy targets. “More me, less corporate,” etc.)

Ask:
(The deliverable: number of options, critique depth, etc.)

# Everyone on Deck (full control panel)
*Use this when the task has many moving parts or you’re building a repeatable system.

Context:
(What’s going on + the relevant backstory in 2–6 sentences.)

Audience:
(Primary + secondary audiences if relevant.)

Channel:
(The format of the final output.)

Decision stage:
(Explore vs decide vs execute. Prevents premature commitment.)

Goal:
(Primary outcome.)

Secondary goals:
(Nice-to-haves that shouldn’t override the main goal.)

Non-goals:
(Explicit “do not optimize” list.)

Draft:
(Current version or “None yet.”)

Constraints:
(Hard limits: must include/must avoid.)

Risk posture:
(How bold/visible/strategic to be. 
Examples: “low drama,” “heavy velvet dominion,” “educational only.”)

Mode:
(Your toggle keyword when relevant: Marketing Mode, DAM, Movement Analyst, etc.)

Scope:
(Size boundaries: number of strategies, paragraphs, options, etc.)

Options wanted:
(Count + type: “5 short + 2 bold,” “3 versions, each under 35 words.”)

Assumptions:
(What I should assume so we don’t stall.)

Unknowns:
(What you suspect you’re missing but don’t want to deep-dive yet.)

Success criteria:
(How you’ll judge the final output as a pass/fail.)

Ask:
(The exact deliverable you want in this turn.)
