Mini Markdown Formatting Cheat Sheet

Use this as a quick reference for Markdown formatting in Obsidian or ChatGPT, with why/when and applied examples.

1. Headings
Syntax:
# Markdown Cheat Sheet

## H2
### H3

Why/When: Structure your notes; Obsidian builds an outline automatically.
Applied Example:
## Tango Class Outline

### Warm-Up

### Partner Exercises
2. Bold and Italic
3. 
Syntax:
**bold text**  
*italic text*

Why/When: Bold for key concepts; Italic for emphasis.

Applied Example:

**Key Principle:** *Connection before complexity.*

3. Inline Code (Backticks)
4. 
Syntax:
`inline code`

Why/When: Show technical terms, file names, or variables; prevents Markdown from interpreting special characters.

Applied Example:

Save your notes in the `Prompt_Library` folder.

4. Code Blocks (Triple Backticks)

Syntax:

```language

Your block of text or code here

```

Why/When: Present longer text or code snippets with syntax highlighting.

  
Applied Example:

```yaml

title: Tango Class Plan

last_updated: 2025-09-26

tags: [tango-class]

```


5. Lists (Bulleted and Numbered)

Syntax:

- Item one

- Item two

  - Sub-item

  
1. Step one

2. Step two

Why/When: Bullets for unordered ideas; numbers for steps.

Applied Example:

- Warm-up

- Connection drill

  - Eye contact exercise

- Musicality segment

6. Links
Syntax:
[Display Text](https://example.com)

Why/When: Make clickable references; link to other notes or external resources.

Applied Example:

[Sign-up Form](https://forms.gle/yourform)

7. Blockquotes

Syntax:

> This is a quote or callout.

Why/When: Highlight quotes, references, or callouts.

Applied Example:

> “Musicality is a shortcut to connection.” — Levi

8. Horizontal Rule
Syntax:

---

Why/When: Visually separate sections.

Applied Example:
## Tango Basics

Content here.

  

---

  

## Advanced Techniques

More content here.

9. Images

Syntax:

![Alt Text](image_url_or_path)

Why/When: Embed diagrams, flyers, or class images directly in notes.


Applied Example:

![ECT Logo](images/ect_logo.png)
  

10. Tables
  

Syntax:

| Column 1 | Column 2 |

|----------|----------|

| A        | B        |

| C        | D        |

Why/When: Organize structured data in a grid.


Applied Example:

| Time  | Activity         |

|-------|------------------|

| 7:00  | Warm-Up           |

| 7:15  | Partner Exercise  |

  

  

  

  

Quick “Why” Summary

  

|   |   |   |
|---|---|---|
|Feature|Use It When|Benefit|
|Headings|Structuring your note|Outlines, collapsible sections|
|Bold/Italic|Highlight or emphasize|Scan quickly for key info|
|Backticks|Show commands/filenames|Prevent misformatting|
|Code Blocks|Long technical text|Syntax highlighting, clarity|
|Lists|Steps or unordered items|Quick scanning|
|Links|Reference material|Clickable connections|
|Blockquotes|Quotes/callouts|Visual distinction|
|Horizontal Rule|Break topics|Visual separation|
|Images|Add diagrams/logos|Inline visuals|
|Tables|Compare data or schedules|Neat grid display|

  

  

  

  

Checklist for Using Markdown Styles

  

  

- Use headings to structure each note.
- Bold/italic key ideas.
- Backticks for filenames or variables.
- Code blocks for YAML, JSON, or prompts.
- Lists for steps or unordered items.
- Links for external/internal references.
- Blockquotes for callouts.
- Horizontal rules for big topic shifts.
- Images and tables for visuals and data.
