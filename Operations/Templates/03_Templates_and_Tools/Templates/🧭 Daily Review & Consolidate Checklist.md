# 🧭 Daily Review & Consolidate Checklist

## 1️⃣ Capture
- [ ] Did I create or discover any new reusable assets today?  
- [ ] Did I articulate or refine any core ideas, frameworks, or teaching principles?  
- [ ] Did I make any public statements (posts, announcements, convos) worth logging or quoting?  
- [ ] Any new scripts, phrases, or ethos lines that capture my tone?

## 2️⃣ Sort
- [ ] Have I filed each new item under the correct PARA location (Project / Area / Resource / Archive)?  
- [ ] Did I cross-link to existing notes (e.g., Calendar Strategy, Communications Tone Reference)?  
- [ ] Do any threads from ChatGPT need to be archived as `.md` files?

## 3️⃣ Close Loops
- [ ] What’s unresolved from today?  
- [ ] Did I make or promise any commitments that need follow-up tasks?  
- [ ] Any interpersonal or strategic situations needing a quick written summary?

## 4️⃣ Synthesize
- [ ] What patterns or shifts did I notice in tone, energy, or effectiveness?  
- [ ] Any emerging principles worth elevating to “Core Frameworks”?  
- [ ] Did any moment today clarify or challenge my brand ethos?

## 5️⃣ Reset
- [ ] Quick inbox sweep (digital + mental).  
- [ ] 1-line daily reflection:  
  `Today I reinforced / discovered / realized ______.`  
- [ ] Tag this note: `#DailyReview` and link to weekly summary.

---

### 🧩 Notes
This checklist is meant to be frictionless: it should take 5–10 minutes.  
Treat it as hygiene, not journaling. Its purpose is structural clarity — not emotional processing.  
End each session with one explicit *carry-forward item* for tomorrow.
